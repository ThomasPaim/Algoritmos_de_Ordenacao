Algoritmos de Ordenação

Bubble Sort:  Compara elementos adjacentes e os troca se estiverem na ordem errada. É um dos mais simples, mas geralmente menos eficiente

Merge Sort: Um algoritmo de "dividir para conquistar", que divide a
lista em sublistas, as ordena e depois as mescla. É conhecido por sua eficiência em grandes conjuntos de dados.

Quick Sort: Também usa a abordagem de "dividir para conquistar",
selecionando um "pivô" e particionando os outros elementos em relação a ele. É conhecido por sua velocidade, com complexidade de tempo de caso médio de O(nlogn)
